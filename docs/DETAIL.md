The **Settings → Firefly III** page sets the instance URL and personal access token, flips the five autoCreate switches for accounts, categories, tags, budgets and piggy banks, and tests the connection — including unsaved URL and token drafts. Saving writes the URL and switches to the local profile configuration through the config editor and the token to the local credential store; both apply immediately, and the token is never shown again.

Supports Firefly III 6.7.x (verified against 6.7.9): accounts can be filtered by active state and read as of a date, categories carry the 6.7.8 color field, credit-card accounts expose their card type and payment date, the budget chart can include budget limits, and `resource=instance` reports the live version, release notes and capability probes.
